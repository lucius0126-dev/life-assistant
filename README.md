# 生活助理

個人用的手機網頁 App：繳費提醒、信用卡回饋、做菜菜單、常用工具捷徑。純 HTML/CSS/JS，沒有外部套件，資料只存在裝置的瀏覽器（localStorage），不上傳。

## 功能（第一版）

- **首頁**：7 天內待繳（過期紅、快到期黃）、今天刷哪張卡、今天吃什麼、快捷工具。
- **繳費**：每月／兩個月／三個月／半年／每年／單次。按「已繳」跳下一期，可復原。自動扣繳的項目過了日期自動往後推。內建電費、水費、牌照稅、房屋稅、地價稅、所得稅、燃料費快速填表。
- **行事曆提醒**：每筆可下載 .ics（照週期重複、提前 N 天早上 9 點提醒）或開 Google 日曆新增；也能一次匯出全部。
- **信用卡**：只存末四碼。結帳日、繳款日、各類別回饋 %、年費條件。依類別排出該刷哪張，並算出今天刷最晚哪天要繳。偵測到完整卡號會擋下不存。勾選「提醒繳卡費」會自動在繳費清單建立每月卡費。
- **菜單**：食譜（食材、步驟、標籤、連結）、今天吃什麼隨機抽、本週要煮、自動合併成買菜清單（同單位份量會相加），可複製貼到 LINE。
- **工具**：拾色（https://color.bidezato.com/）等連結，可新增、改圖示、排序。
- **備份**：匯出／匯入 JSON；手機上走分享選單，可存到「檔案」或傳到 LINE。可離線使用。

## 本機預覽

```powershell
python -m http.server 8790 --bind 127.0.0.1
```

開啟 http://localhost:8790 。要用 http 伺服器開，直接雙擊 index.html 不能用（ES module 限制）。

## 測試

```powershell
node verify-logic.mjs
```

測日期推算、週期繳費、信用卡結帳／繳款日、刷卡推薦、卡號偵測、食材合併、行事曆檔格式。

圖示改了圖案後重新產生 PNG：`python scripts/make_icons.py`

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 頁面骨架、底部分頁、表單抽屜 |
| `app.js` | 畫面、互動、儲存、備份、行事曆下載 |
| `logic.js` | 純計算邏輯（不碰畫面），給 `verify-logic.mjs` 測試 |
| `style.css` | 樣式（含深色模式） |
| `sw.js` | 離線快取；**更新網站時把 `CACHE` 版本號 +1** |
| `manifest.webmanifest`、`icon*` | 加到主畫面用的名稱與圖示 |

## 上線（之後）

和拾色一樣放 GitHub Pages，例如 `life.bidezato.com`。程式碼公開沒關係，個人資料不在程式碼裡，只在各自裝置的瀏覽器中。手機要用 HTTPS 網址才能安裝成 App。

## 注意事項

- **iPhone 一定要加到主畫面**：Safari 分頁的網站資料，7 天沒開可能被清掉；主畫面 App 不會。而且主畫面 App 和 Safari 分頁的資料是分開的，請加到主畫面後再輸入。
- 換手機、清除瀏覽器資料前先匯出備份。超過 30 天沒備份，首頁會提醒。
- 尚未在真機確認：iPhone 主畫面 App 裡下載 .ics 是否會直接跳「加入行事曆」、手機分享備份檔、安裝流程。
- Android 的 Google 日曆 App 不能直接開 .ics，請用每筆的「Google 日曆」按鈕，或在電腦的 Google 日曆網頁「設定 → 匯入」。
- 稅款日期是一般年度的法定期限，若遇延期請自行修改。
